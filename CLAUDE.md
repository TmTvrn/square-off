# Square Off: working notes for AI agents

A Godot 4.7 project that's meant to be built mostly through code and text, while staying easy for a person to read and tweak in the editor.

## Principles
- **Lean.** No menus, no save system, no framework layers. Add a system only when the fight needs it.
- **Text-first, editor-friendly.** Scenes are hand-readable `.tscn` files. Give nodes plain, descriptive names (`CatwalkLeft`, `ContactHitbox`). Expose every tunable as an `@export` with a `##` doc comment, grouped with `@export_group`.
- **Strictly 2D primitives.** All art is drawn through `GeoShape` (`scripts/core/geo_shape.gd`), `ArenaBlock`, `SpikeStrip`, or the FX layers. No textures yet.
- **Shape, fill and color mean things.** Squares are bodies, circles are projectiles, triangles are hazards. An outline is a warning; a fill is real. Colors come only from `Palette` roles. Never hard-code a color, and never give a hue a second meaning.
- **Value hierarchy:** background < grid < arena < hazards < boss < player < projectiles < flashes. Check with G (grayscale).
- **Juice goes through `Juice`** (freeze, slowmo, shake, kick, ripple, sparks, shards, ring, ghost, dust, impact), so feel stays tunable in one place.

## Conventions
- Typed GDScript, tabs, and `snake_case`. Warnings are treated as errors (for example, inferring a type from a Variant), so annotate types where needed.
- Physics runs at 60 Hz with physics interpolation on. Call `reset_physics_interpolation()` after teleports.
- Physics layers: 1 world, 2 one_way, 3 player, 4 enemy, 5 hazard, 6 player_attack, 7 enemy_attack, 8 enemy_only_floor.
- Damage: a `Hitbox` (Area2D) hurts the player; the player's hurtbox polls for them every tick. Attacks call `Hurtbox.receive_hit()` on enemies.
- Minions extend `Minion` (`scripts/minions/minion.gd`) and only implement `_behave()`. They spawn through `Game.spawn()` into `Enemies` and sit in the "minions" group. Warm reds mean enemies of every size; size and silhouette tell them apart.
- Boss behavior is the `_brain()` coroutine in `scripts/boss/boss.gd`. Waits use game time, so freeze frames pause the boss as well.
- Movement numbers live in `PlayerTuning`. Jumps are authored as height plus time-to-apex; gravity is derived from those.
- Sounds are generated by `tools/generate_sfx.py`. Add the name to `Sfx.SOUNDS` when you add a recipe.

## Verify changes
```bash
godot --headless --path . --quit-after 120                    # loads the main scene; look for SCRIPT ERROR
godot --headless --path . res://tests/test_feel.tscn          # feel checks, exit code 1 on failure
godot --path . -- --capture-dir="$PWD/captures" --capture-at=1,2,3 --autoplay=combat --spawn-x=1560
godot --path . -- --capture-dir="$PWD/captures" --capture-at=2.5 --boss-attack=needle_rain --boss-phase=2
```
The last command plays a scripted input timeline and saves screenshots to `captures/` (gitignored), so you can look at the result. See `scripts/debug/debug_tools.gd`.
